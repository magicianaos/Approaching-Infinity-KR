어프로칭 인피니티(Approaching Infinity) 한글패치 v1.1.1 (정식판 + 데모판)
====================================================

[설치 방법]
1. 이 압축 파일을 풀어 주세요. 풀린 폴더를 게임 폴더 안에 넣는 것을 권장합니다.
   예) C:\Program Files (x86)\Steam\steamapps\common\Approaching Infinity\한글패치_v1.1.1
   (다른 곳에 풀어도 됩니다. 스팀 설치 위치에서 게임 폴더를 자동으로 찾고, 못 찾으면 경로를 물어봅니다.)
2. "1_한글패치_설치.bat"을 더블클릭합니다.
3. 검은 창에 "설치 끝"이 나오면 아무 키나 눌러 닫고 게임을 실행합니다.

- 설치할 때 바뀌는 원본 파일은 게임 폴더의 "한글패치_원본백업" 폴더에 자동으로 보관됩니다.
- Windows가 "PC 보호" 창을 띄우면 "추가 정보" → "실행"을 눌러 주세요.
- 게임 폴더가 Program Files 안에 있어 권한 오류가 나면, bat 파일을 우클릭 → "관리자 권한으로 실행"을 해 주세요.

[원본(영어)으로 되돌리기]
- "2_원본_복구.bat"을 실행합니다.
- 또는 스팀 라이브러리 → 게임 우클릭 → 속성 → 설치된 파일 → "게임 파일 무결성 확인"을 해도 됩니다.

[게임이 업데이트되면]
- 스팀 업데이트로 게임 파일이 바뀌면 영어로 돌아가거나 게임이 제대로 동작하지 않을 수 있습니다.
- 설치 프로그램은 패치를 만든 게임 버전과 다르면 설치하지 않고 멈춥니다. 새 버전용 패치를 기다려 주세요.
- 대상 버전: 2026년 9월 기준 스팀 정식판 v2.2.1 (SHA256 16c66c175341…), 데모판 v2.2.0jk-DEMO (SHA256 7ee7d84b7ba0…)

[v1.1.1 고친 점]
- 장치(함선·상륙조 장비) 효과 설명의 앞부분이 잘려 보이던 문제 수정 (예: 굴착기, 등반 장비)

[정식판과 데모판]
- 정식판과 데모판(Approaching Infinity Demo)을 모두 지원합니다. 설치 프로그램이 지금 깔린 쪽을 알아서 판별합니다.
- 스팀에서 데모판은 정식판과 같은 폴더에 설치됩니다. 둘을 같이 설치하면 나중에 받은 쪽 파일로 덮어씌워지니, 한쪽만 설치해 두는 것을 권장합니다.
- 정식판↔데모판을 바꿨거나 스팀이 파일을 다시 받았다면 "1_한글패치_설치.bat"을 한 번 더 실행하면 됩니다.

[알아 두실 점]
- 한글판에서 만든 함장·함선·행성 이름은 한글로 저장됩니다. 원본으로 되돌리면 그 이름이 네모 글자로 보입니다. (새 게임은 정상)
- 불러오기 화면 둘째 줄과 일부 외계 종족 통신문은 외계 문자 전용 그림 글꼴을 쓰기 때문에 영어/외계 문자로 남겨 두었습니다.
- 그림 안에 그려진 영어 글자와 타이틀의 "Approaching Infinity Classic"(별도 실행 파일)은 번역하지 않았습니다.
- 스팀 상품 이름(예: "Approaching Infinity - Classic Plus")은 영어 그대로 두었습니다.
- 가끔 효과음이 모두 멈추는 현상은 영어 원본에서도 생기는 게임 엔진 쪽 증상입니다. 이때는 게임을 다시 실행해 주세요.

[글꼴]
- media\Kanit-Regular.ttf 는 Kanit(Cadson Demak)과 Noto Sans CJK KR(Adobe)을 합친 수정 글꼴("AI Hangul")입니다.
  두 글꼴 모두 SIL Open Font License 1.1 을 따릅니다. 자세한 내용은 "글꼴_라이선스_OFL.txt"를 보세요.

[저작권]
- 원작 게임의 모든 권리는 원 개발자에게 있습니다. 이 패치는 비공식 팬 번역이며, 게임을 구매한 분만 사용할 수 있습니다.
- 이 패치에는 게임 본체가 들어 있지 않습니다. 정품 게임이 설치되어 있어야 합니다.
